======================================
  칼럼 레퍼런스 폴더 사용법
======================================

이 폴더에 기존에 작성하신 칼럼을 .txt 또는 .md 파일로 넣어주세요.
에이전트가 이 칼럼들의 문체와 스타일을 학습하여 새 글을 생성합니다.

[파일명 규칙]
- 자유롭게 지어도 됩니다
- 예시:
  서울_아파트_투자전략.txt
  2025_부동산_전망.md
  재건축_투자_가이드.txt
  강남_재건축_분석.txt
  전세시장_동향_분석.md

[파일 내용]
- 칼럼 제목과 본문을 그대로 복사해서 넣으세요
- HTML 태그가 포함되어도 괜찮습니다
- 최소 3~5개 이상의 칼럼을 넣으면 스타일 학습이 더 정확해집니다

[참고]
- 가장 최근에 수정된 파일 5개를 우선 참조합니다
- 파일이 많을수록 다양한 스타일을 학습합니다
