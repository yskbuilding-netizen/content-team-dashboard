임차인 업종 분석 — 빌사남 실전 가이드

==================================================

1. 임차인 업종별 특성

/ F&B (식음료) /
- 가장 흔한 임차인 유형
- 장점: 높은 임대료 가능, 유동인구 유발
- 단점: 폐업률 높음 (자영업 폐업 100만 시대), 원상복구 비용 큼
- 핵심: 프랜차이즈 vs 개인 매장 구분 필요
  → 프랜차이즈: 안정적이나 임대료 협상력 강함
  → 개인 매장: 임대료는 높지만 폐업 리스크 높음
- 트렌드: 외국인 관광객 대상 식당이 강세 (명동, 성수, 한남)

/ 카페 /
- 상권 형성의 핵심 업종
- 대형 프랜차이즈(스타벅스, 투썸): 안정적 장기 임차인
- 개인 카페: 상권 초기 진입 → 상권 성숙기에 임대료 감당 못하고 퇴거
- 인스타 감성 카페: 단기 유행에 민감, 2~3년 주기로 교체 잦음

/ 리테일 (소매) /
- K-뷰티, K-패션: 외국인 관광객 타겟 (명동, 강남)
- 올리브영: 명동역 인근 하루 매출 1억 이상
- 편의점: 안정적이나 임대료 낮음
- 브랜드 팝업스토어: 단기 임대지만 상권 활성화 효과 큼 (성수동 연무장길)

/ 오피스 (사무실) /
- 대기업/금융기관: 가장 안정적
- 중소기업/스타트업: 투자심리 위축 시 가장 먼저 축소
- IT기업: 판교 중심이나 강남역 수요도 꾸준
- 공유오피스: WeWork 등, 코로나 이후 수요 감소세

/ 의료/미용 /
- 피부과, 성형외과: 강남, 청담, 압구정 중심
- 외국인 의료관광 수요 급증 (중국, 일본, 동남아)
- 청담동 미용실: 외국인 고객 비중 50% 이상
- 통역사 배치하는 매장 증가 → 글로벌 서비스 공간화

/ 교육/학원 /
- 안정적 장기 임차인
- 위치보다 접근성 중요
- 인테리어 투자가 크기 때문에 쉽게 이동하지 않음

==================================================

2. 업종별 임대 전략

/ 1층 /
- 최적: F&B, 리테일, 카페
- 유동인구 직접 유입 가능한 업종
- 가시성(visibility)이 임대료를 결정
- 코너 자리 프리미엄 20~30% 이상

/ 2~3층 /
- 최적: 카페(루프탑/뷰), 학원, 뷰티
- 1층 대비 임대료 30~50% 저렴
- 엘리베이터 유무가 핵심 경쟁력

/ 지하 /
- 최적: 주점, 와인바, 피트니스
- 환기/소방 시설 확인 필수
- 임대료 가장 저렴하나 공실 리스크도 가장 높음

/ 4층 이상 /
- 최적: 오피스, 학원, 의료
- 엘리베이터 필수
- 전용률이 임대 경쟁력 좌우

==================================================

3. 임차인 유치 실전 팁

- 렌트프리(무상 임대기간): 시장 침체기 3~6개월 제공 일반적
- 인테리어 비용 지원: 평당 30~50만 원 수준으로 협의
- 권리금 인정 여부: 상권에 따라 다름
- 임대차 기간: 최소 2년, 안정적 임차인은 5년 권장
- 임대료 인상: 연 3~5% 수준이 적정
- 보증금 비율: 월세의 10~12배가 일반적

==================================================

4. 주의할 임차인

- 단기 팝업만 원하는 임차인: 공실 리스크 높음
- 업종 변경 빈번한 임차인: 인테리어 원상복구 문제
- 법인 아닌 개인 임차인: 폐업 시 보증금 회수 어려울 수 있음
- 금지 업종 확인: 용도지역에 따라 유흥/숙박 불가한 경우 있음
