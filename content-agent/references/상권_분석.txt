상권 분석 — 빌사남 실전 가이드

==================================================

1. 상권 양극화 현황 (2026년 기준)

/ 잘되는 상권 — 더 잘된다 /
- 도산공원, 성수동 연무장길, 한남동, 명동, 청담동 명품거리
- 공실률 낮음, 임대료 계속 상승, 건물 가격 최고가 경신
- 외국인 관광객이 상권 성장의 핵심 동력

/ 안 되는 상권 — 더 안 된다 /
- 자영업자 폐업률 사상 최대 (2025년 100만 명 돌파)
- 고물가로 소비 위축
- 온라인 쇼핑 확대로 오프라인 매장 경쟁력 약화
- 배달 플랫폼 수수료 부담 가중

/ 양극화의 원인 /
- 소비 인구 감소 (고령화, 저출생)
- 외국인 관광객이 특정 지역에만 집중
- SNS를 통한 핫플레이스 쏠림 현상
- 대기업/프랜차이즈의 핵심 상권 집중

2. 외국인이 오는 상권이 살아남는다

/ 왜 외국인이 중요한가 /
- 국내 소비인구는 계속 줄어들고 있음
- 젊은 인구 감소, 고령층 증가 → 소비세대 축소
- 반면 외국인 관광객은 매년 폭발적 증가
- 넷플릭스/OTT로 한국 문화 콘텐츠 소비 → 직접 방문으로 이어짐

/ 외국인이 찾는 상권 특성 /
- K-뷰티: 명동 올리브영 (하루 매출 1억+)
- K-푸드: 드라마에 나온 음식/장소
- K-의료: 성형외과, 피부과 (청담, 압구정, 강남)
- K-패션: 성수동 브랜드 팝업
- K-문화: 카페, 갤러리, 전시 (한남, 성수)

/ 외국인 관광 상권 TOP /
1. 명동: K-뷰티 중심, 유동인구 서울 최다
2. 성수동: 브랜드 경험, 줄 서는 관광객
3. 한남동: 프리미엄 다이닝, 갤러리
4. 청담동: 의료관광, 명품, 프리미엄 미용
5. 홍대/연남: 클럽, 카페, 젊은 관광객

/ 시사점 /
- 빌딩 투자 시 "이 지역에 외국인이 찾아오는가" 확인 필수
- 외국인 매력도가 없는 상권은 장기적으로 쇠퇴 가능성
- 관광객 = 단순 유동인구가 아닌 상권의 수준을 끌어올리는 존재

3. 상권 생존/쇠퇴 판단 기준

/ 생존하는 상권의 특징 /
- 역세권 + 평탄한 지형
- 대로변 가시성 좋음
- 오피스 빌딩 상주인구 多
- 호텔/숙박시설 인접
- 공원/산책로 조성 (연남동 경의선 숲길 사례)
- 외국인 관광객 유입
- 다양한 업종 혼합 (F&B + 리테일 + 카페 + 문화)

/ 쇠퇴하는 상권의 특징 /
- SNS 유행으로만 떴다가 사라짐 (경리단길 사례)
- 접근성 나쁨 (언덕, 골목 안쪽)
- 단일 업종 집중 (카페만 있는 거리)
- 대형 쇼핑몰 인근 (빨대 효과)
- 임대료만 오르고 매출은 안 따라가는 곳

/ 경리단길 교훈 /
- 이태원역 인근 임대료 상승 → 경리단길로 이동
- 위치 좋지 않았지만 임대료 저렴 → 유행 타고 상승
- 유행 끝나자 → 공실 증가, 상권 쇠퇴
- 교훈: 접근성 없는 유행 상권은 장기 투자에 부적합

4. 상권 분석 실전 도구

/ 디스코(DISCO) /
- 실거래가 확인, 건축물대장 열람
- 초보자도 쉽게 사용 가능
- 빌딩 투자 시작할 때 거의 필수

/ 밸류맵(ValueMap) /
- 토지/건물 개별 가치 분석
- 매입 적정가 판단
- 주변 시세 비교

/ 네이버부동산 /
- 주변 임대시세, 공실률 확인
- 매입 검토 중인 건물 주변 매물 비교
- 리모델링 후 예상 임대료 시뮬레이션

/ 로드뷰 히스토리 분석 /
- 네이버: 2010년 9월부터 로드뷰 서비스
- 카카오맵: 2008년부터 서비스
- 연도별 히스토리를 봐야 하는 이유:
  ① 공실 기간 파악 (임대 현수막이 몇 년째 걸려있는지)
  ② 신축/리모델링 전후 변화 확인
- 데이터는 상상력을 키워주는 도구

/ 키스콘(KISCON) /
- 시공사 정보 확인
- 건설업 면허, 시공능력 평가액, 매출, 신용등급
- 리모델링/신축 시 시공사 선정 전 필수 확인

5. 임대시장 현황 (2026년 기준)

/ 상가 임대 /
- 경기 침체로 자영업자 폐업 급증
- 렌트프리(무상 임대기간) 늘어나는 추세
- 인테리어 비용 지원 조건 제시하는 건물주 증가
- 임차인 입장에서는 좋은 조건으로 입주 가능한 시기

/ 오피스 임대 /
- 프라임급 빌딩: 비교적 안정적
- 소형 빌딩(꼬마빌딩): 직격타
  → 임차인 대부분 중소기업, 스타트업, 개인사업자
  → 투자심리 위축 → 스타트업 확장 수요 감소
- 강남/역삼/선릉 빌딩 공실률 상승 추세

/ 핵심 상권 예외 /
- 도산공원, 성수동, 한남동, 명동, 청담동: 여전히 강세
- 공실률 낮고, 임대료 상승 중
- 건물 가격도 최고가 경신

6. 용적률 인센티브 기회 (2025.5 ~ 2028.5)

- 서울시 3년 한시적 용적률 완화
- 제2종 일반주거: 200% → 250%
- 제3종 일반주거: 250% → 300%
- 대지 100평 기준: 연면적 200평 → 250평 (한 층 이상 추가)
- 임대면적 확대 → 수익률 증가 → 매각 시 자산가치 상승
- 2028년 5월 이후 원래 용적률로 복귀 가능성
- 지금 신축/리모델링 계획 중이면 설계와 인허가를 서두를 시기
- 단, 일조권 사선 영향으로 모든 대지가 해당되진 않음
- 반드시 건축사와 사전 검토 필요
