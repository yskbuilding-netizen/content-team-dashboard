1. A급 빌딩의 3가지 기준

첫째, 거래가 되는 곳에 있어야 한다.
- 시장이 어려워져도 매수 대기자가 있는 지역
- 환금성이 가장 중요한 판단 기준
- 2025년 전국 상업/업무용 부동산 거래의 약 60%가 서울에서 이루어짐

둘째, 입지가 좋아야 한다.
- 싼 곳이 아닌 좋은 곳을 제값에 매입
- 접근성: 역세권, 대로변 접근, 평탄한 지형
- 가시성: 도로에서 건물이 잘 보이는가
- 유동인구: 상주인구 + 유동인구 + 체류인구

셋째, 가치 상승 가능성이 있어야 한다.
- 리모델링/신축으로 가치를 올릴 수 있는 건물
- 용적률 여유가 있는 건물
- 노후 건물이되 구조가 튼튼한 건물 (철근콘크리트)

2. 서울 핵심 상권별 분석

/ 강남역 /
- 특징: 대기업 본사, 금융기관, 학원가 밀집
- 장점: 거래 꾸준, 매수 대기자 항상 존재
- 임대: 오피스 수요 안정적, 1층 F&B 프리미엄
- 유의: 가격 높음, 진입장벽 높음
- 외국인: 신분당선으로 판교 IT인력 유입

/ 역삼/선릉 /
- 특징: IT기업, 스타트업 밀집
- 장점: 오피스 수요 꾸준
- 단점: 스타트업 경기에 민감, 공실률 변동
- 최근: 공실률 상승 추세 (투자심리 위축)

/ 성수동 연무장길 /
- 특징: 브랜드 팝업, 카페, 갤러리, 편집숍
- 장점: 외국인 관광객 폭증, SNS 핫플
- 공실률 낮음, 임대료 계속 상승
- 유의: 일부 골목은 유행 끝나면 공실 리스크
- 핵심: 연무장길 메인 도로변이 가장 안정적

/ 한남동 /
- 특징: 고급 F&B, 갤러리, 프리미엄 브랜드
- 장점: 체류인구 많음 (한남 주거지+이태원 관광)
- 외국인 비중 높음
- 임대료 상승세 지속
- 유의: 이태원 본거리와의 거리에 따라 상권 차이 큼

/ 도산공원 /
- 특징: 프리미엄 상권, 명품 브랜드, 고급 식당
- 장점: 부유층 소비, 외국인 관광객
- 공실률 매우 낮음
- 유의: 진입가격이 매우 높음

/ 명동 /
- 특징: K-뷰티 중심지, 외국인 관광 1번지
- 코로나 시기 공실률 50% → 현재 한 자릿수로 회복
- 유동인구 서울 최다 수준
- 올리브영 매장 하루 매출 1억 이상
- 핵심: 외국인 관광객 회복이 상권 전체를 살림

/ 청담동 /
- 특징: 명품거리, 성형외과, 프리미엄 미용실
- 외국인 의료/미용 관광 수요
- 직원 대부분 영어/중국어/일본어 구사
- 통역사 별도 배치하는 매장도 있음

/ 연남동 /
- 특징: 경의선 숲길 주변 카페/식당
- 장점: 공원이 상권을 키운 대표 사례
- 체류시간이 길어 소비 유발
- 유의: 메인 도로와 골목 차이 큼

/ 이태원 /
- 특징: 글로벌 상권, 다국적 식당
- 코로나 이후 회복 중이나 완전 회복은 아님
- 경리단길: 유행 끝난 대표 사례 (임대료 상승 → 공실 → 쇠퇴)
- 핵심 교훈: SNS 유행 상권은 장기 투자에 부적합

3. 입지 판단 체크리스트

/ 접근성 /
□ 지하철역 도보 5분 이내
□ 대로변 접근 용이
□ 언덕/내리막 없이 평탄
□ 주차 가능 여부

/ 유동인구 /
□ 평일 낮 유동인구
□ 평일 저녁 유동인구
□ 주말 유동인구
□ 외국인 관광객 비중

/ 상권 특성 /
□ 상주인구 (오피스 직장인)
□ 체류인구 (카페/식당/관광)
□ 소비력 (평균 객단가)
□ 경쟁 매장 수

/ 거래 데이터 /
□ 최근 3년 거래량
□ 주변 매물 호가
□ 실거래가 추이
□ 공실률 추이

/ 미래 가치 /
□ 개발 호재 (오피스 빌딩 신축, 호텔 등)
□ 교통 변화 (GTX, 지하철 연장)
□ 정책 변화 (용적률 인센티브 등)
□ 인구 흐름 (2030 유입 여부)

4. 빌딩과 주거시설의 호재는 다르다

/ 빌딩에 좋은 호재 /
- 대형 오피스 빌딩 입주 → 상주인구 증가 → 주변 상권 활성화
- 호텔 신축 → 투숙객 소비 → 상권 성장
- 공원/산책로 조성 → 체류시간 증가 → 상권 확대 (연남동 사례)

/ 빌딩에 나쁜 호재 /
- 대형 쇼핑몰 입점 → 빨대 효과 → 주변 소비 흡수 (잠실 롯데타워)
- 지하철 연장 → 핵심 상권으로 이동 → 로컬 상권 약화 (신분당선 → 강남 집중)

핵심: "이용자의 입장에서 생각하라"
- 나라면 이 상권을 일부러 찾아갈까?
- 주거시설 호재 = '살기 좋은 환경'
- 빌딩 호재 = '찾고 싶은 거리'
