KB 부동산 주간 시세 — 상업용 빌딩 참고 데이터
(2026년 4월 기준)

==================================================

1. 금리 현황

/ 기준금리 /
- 한국은행 기준금리: 2.50% (2026.4 기준)
- 2022년 최고점(3.50%) 대비 1.0%p 인하
- 추가 인하 가능성 존재 (하반기 2.25% 전망)

/ 빌딩 담보대출금리 /
- 개인 명의: 4.0~5.5%
- 법인 명의 (우량): 3.0~4.0%
- 법인 명의 (일반): 3.5~4.5%
- 3년 전 대비 약 절반 수준

/ 금리별 이자 부담 (30억 대출 기준) /
- 금리 3.0%: 월 750만 원 / 연 9,000만 원
- 금리 4.0%: 월 1,000만 원 / 연 1.2억 원
- 금리 5.0%: 월 1,250만 원 / 연 1.5억 원
- 금리 7.0%: 월 1,750만 원 / 연 2.1억 원
→ 금리 1% 차이 = 연 3,000만 원 차이

==================================================

2. 서울 상업용 빌딩 거래 동향

/ 거래량 추이 /
- 2022년 상반기: 활발 (저금리 마지막 구간)
- 2022년 하반기: 급감 (금리 급등)
- 2023년: 역대 최저 (거래 절벽)
- 2024년: 회복 시작 (금리 안정)
- 2025년: 점진적 증가
- 2026년 1분기: 전년 동기 대비 약 15~20% 증가

/ 지역별 거래 활성도 /
- 강남구: 가장 활발, 매수 대기자 항상 존재
- 서초구: 안정적 거래량
- 성동구(성수): 거래량 급증, 가격 상승
- 용산구(한남/이태원): 회복세
- 마포구(연남/홍대): 보합
- 영등포/여의도: 오피스 중심 거래

/ 규모별 거래 동향 /
- 20~30억 (꼬마빌딩): 거래 가장 활발, 개인 투자자 진입
- 30~50억: 법인 투자자 중심
- 50~100억: 자산가/법인 위주
- 100억 이상: 기관/대형 법인

==================================================

3. 주요 상권 평당 시세 (대지 기준, 참고용)

/ 강남역 /
- 대로변: 평당 1.5~3.0억
- 이면: 평당 0.8~1.5억
- 임대료(1층): 평당 15~25만 원/월

/ 역삼/선릉 /
- 대로변: 평당 1.2~2.5억
- 이면: 평당 0.7~1.2억
- 임대료(1층): 평당 12~20만 원/월

/ 성수동 /
- 연무장길 메인: 평당 1.0~2.0억
- 이면: 평당 0.5~1.0억
- 임대료(1층): 평당 10~18만 원/월
- 최근 3년 상승률: 약 30~50%

/ 한남동 /
- 메인도로: 평당 1.2~2.5억
- 이면: 평당 0.6~1.2억
- 임대료(1층): 평당 12~20만 원/월

/ 도산공원 /
- 메인: 평당 2.0~4.0억
- 이면: 평당 1.0~2.0억
- 임대료(1층): 평당 20~35만 원/월

/ 명동 /
- 메인: 평당 3.0~5.0억+
- 임대료(1층): 평당 25~50만 원/월
- 외국인 관광 회복 후 급상승

==================================================

4. 임대수익률 현황

/ 평균 임대수익률 (Cap Rate) /
- 서울 전체 상업용: 약 3.5~4.5%
- 강남 핵심: 약 2.5~3.5% (시세차익 기대)
- 비핵심: 약 4.5~6.0% (수익률은 높으나 환금성 낮음)

/ 수익률 트렌드 /
- 금리 인하 → Cap Rate 하락 → 가격 상승
- 핵심 지역은 수익률 낮아도 환금성으로 보상
- 비핵심 지역은 수익률 높아도 매각 어려움
