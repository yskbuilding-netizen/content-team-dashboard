자영업 폐업률 통계 및 빌딩 공실 위험도 분석

==================================================

1. 자영업 폐업 현황

/ 연도별 폐업 추이 /
- 2020년: 약 78만 건 (코로나 시작)
- 2021년: 약 82만 건
- 2022년: 약 88만 건
- 2023년: 약 93만 건
- 2024년: 약 97만 건
- 2025년: 약 100만 건 돌파 (역대 최대)

/ 업종별 폐업률 (2025년 기준) /
- 음식점: 약 25% (4곳 중 1곳 폐업)
- 소매업: 약 20%
- 숙박업: 약 18%
- 개인서비스: 약 15%
- 교육서비스: 약 12%

/ 폐업 원인 /
1. 고물가로 소비 위축 → 매출 감소
2. 인건비 상승 (최저임금 인상)
3. 원자재비/식자재비 급등
4. 배달 플랫폼 수수료 부담 (20~30%)
5. 코로나 시기 대출 → 금리 급등 → 이자 감당 못함
6. 온라인 쇼핑 확대 → 오프라인 경쟁력 약화

==================================================

2. 지역별 폐업 밀집도

/ 폐업률 높은 지역 /
- 서울 외곽 상권 (비핵심 지역)
- 유행이 지난 ○○길 상권
- 대형 쇼핑몰 인근 (빨대 효과)
- 주거지 내 골목 상권

/ 폐업률 낮은 지역 /
- 강남/역삼/서초: 오피스 상주인구 뒷받침
- 성수동: 외국인 + 브랜드 팝업 수요
- 한남동: 프리미엄 소비층
- 명동: 외국인 관광 회복
- 청담동: 의료/미용/명품 수요

==================================================

3. 폐업률과 빌딩 공실 위험도 연동

/ 공실 위험도 산정 기준 /

[낮음 - 안전] 폐업률 10% 이하
- 해당 지역: 강남, 도산공원, 명동 핵심
- 임대료 상승 가능
- 공실 발생 시 빠른 재임대

[보통 - 관리 필요] 폐업률 10~20%
- 해당 지역: 역삼, 선릉, 마포 일부
- 임차인 관리 중요
- 렌트프리 조건 검토

[높음 - 주의] 폐업률 20~30%
- 해당 지역: 서울 외곽, 유행 지난 상권
- 공실 장기화 가능성
- 임대료 하향 조정 필요

[매우 높음 - 위험] 폐업률 30% 이상
- 해당 지역: 쇠퇴 상권, 지방 일부
- 투자 자체를 재고
- 매각 검토 필요

==================================================

4. 업종 교체 트렌드 (폐업 후 새로 들어오는 업종)

/ 퇴장하는 업종 /
- 일반 한식당 (경쟁 과다)
- 프랜차이즈 치킨/커피 (포화)
- 노래방 (수요 감소)
- 오프라인 소매 (온라인 대체)
- 인쇄소/복사점 (디지털 전환)

/ 진입하는 업종 /
- 무인매장 (무인카페, 무인세탁)
- 특화 다이닝 (오마카세, 파인다이닝)
- K-뷰티/K-패션 (외국인 타겟)
- 공유오피스/스터디카페
- 피트니스/필라테스
- 반려동물 관련 (호텔, 카페, 병원)
- 팝업스토어 (단기 임대)

==================================================

5. 빌딩 건물주 대응 전략

/ 공실 예방 /
- 임차인 업종 다각화 (한 업종 의존 위험)
- 장기 임대 계약 유도 (3~5년)
- 프랜차이즈 우선 유치 (폐업 리스크 상대적으로 낮음)
- 1층 업종은 유동인구 유발형으로 (카페, 편의점, 베이커리)

/ 공실 발생 시 /
- 렌트프리 3~6개월 제공 (시장 상황에 따라)
- 인테리어 비용 일부 지원 (평당 30~50만 원)
- 임대료 인하보다 렌트프리가 유리 (임대료 기준 유지)
- 인근 중개사 3곳 이상에 매물 등록

/ 장기 전략 /
- 리모델링으로 건물 경쟁력 강화
- 외국인 유입이 많은 상권이면 간판/메뉴 다국어 지원
- 건물 1층에 앵커 테넌트(대형 프랜차이즈) 확보

==================================================
