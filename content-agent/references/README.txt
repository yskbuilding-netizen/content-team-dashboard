======================================
  참고자료 폴더 사용법
======================================

이 폴더에 콘텐츠 작성에 활용할 자료를 넣어주세요.
에이전트가 글/스크립트 작성 시 이 자료들을 참고합니다.

[넣을 수 있는 자료 종류]
- 부동산 통계 데이터 (KB부동산, 한국부동산원 등)
- 뉴스 기사 스크랩
- 정책 변화 내용 (금리, 세금, 규제 등)
- 시장 리포트
- 강의 자료 / 세미나 내용
- 본인 유튜브 영상 대본
- 실거래가 데이터
- 상권 분석 자료

[파일 형식]
- .txt 또는 .md 파일로 저장
- 파일명은 자유 (예: 2026년_서울_빌딩거래량.txt)

[파일명 예시]
- KB_주간시세_2026년4월.txt
- 서울_상업용빌딩_거래동향.txt
- 금리전망_2026하반기.txt
- 강남_성수_상권비교.txt
- 자영업_폐업률_통계.txt
- 용적률_인센티브_정리.txt

[참고]
- 파일이 많을수록 다양한 데이터 활용 가능
- 최근 자료일수록 좋음
- 큰 파일도 OK (앞부분 8000자 자동 참조)
