금리 전망 및 빌딩 투자 시뮬레이션
(2026년 하반기 전망)

==================================================

1. 기준금리 전망

/ 현재 /
- 한국은행 기준금리: 2.50% (2026.4 기준)
- 미국 연준(Fed) 기준금리: 4.25~4.50%

/ 하반기 전망 /
- 한국은행: 추가 인하 가능 (2.25~2.50% 예상)
- 인하 근거: 내수 부진, 소비 위축, 수출 둔화
- 동결 근거: 원/달러 환율 불안, 가계부채 관리

/ 시나리오별 전망 /
시나리오 A (낙관): 기준금리 2.00%까지 인하
→ 빌딩 담보대출 법인 2%대 진입 가능
→ 거래 활성화, 가격 상승 본격화

시나리오 B (기본): 기준금리 2.25~2.50% 유지
→ 현 수준 대출 조건 유지
→ 거래 점진적 회복

시나리오 C (보수): 기준금리 2.50% 동결 또는 소폭 인상
→ 환율/물가 불안 시
→ 거래 보합, 가격 횡보

==================================================

2. 금리 변동별 수익률 시뮬레이션

/ 기준: 30억 빌딩, 대출 15억 (LTV 50%) /

[금리 3.0%]
- 연 이자: 4,500만 원
- 월 이자: 375만 원
- 연 임대수익 1.2억 기준 순수익: 7,500만 원

[금리 3.5%]
- 연 이자: 5,250만 원
- 월 이자: 437만 원
- 연 임대수익 1.2억 기준 순수익: 6,750만 원

[금리 4.0%]
- 연 이자: 6,000만 원
- 월 이자: 500만 원
- 연 임대수익 1.2억 기준 순수익: 6,000만 원

[금리 5.0%]
- 연 이자: 7,500만 원
- 월 이자: 625만 원
- 연 임대수익 1.2억 기준 순수익: 4,500만 원

→ 금리 0.25% 변동 시 연 이자 약 375만 원 차이
→ 금리 1% 변동 시 연 이자 1,500만 원 차이
→ 금리 2% 변동 시 연 이자 3,000만 원 차이 (임대료 3개월치)

4. 대출 타이밍 전략

/ 연간 대출 유리 시기 /
- 1월 중순~3월: 가장 유리 (연간 한도 새로 배정)
  → 단, 1월 초는 인사이동 시기라 피하기
- 4월~6월: 차선 (상반기 내 실행 권장)
- 7월: 하반기 예산 풀리는 시점 (놓쳤으면 여기)
- 10월 이후: 한도 소진, 조건 나빠짐, 피해야 함

/ 금리 협상 전략 /
1. 은행 3곳 이상 비교 (같은 금액에 1% 차이 흔함)
2. 법인 재무제표 정리 (신용등급 영향)
3. 예금 실적 쌓기 (1억 이상 예치 → 내부 평가점수 상승)
4. 지점장급과 직접 상담 (담당자 재량 폭 큼)
5. 잔금일을 연초로 조정 가능하면 유리
