================================
  카드뉴스 이미지 저장 폴더
================================

이 폴더에 카드뉴스용 사진을 저장하세요.

[파일명 규칙]
- 영문 + 숫자 + 하이픈(-) 또는 언더스코어(_)만 사용
- 한글, 공백 사용 금지

[좋은 예시]
- seongsu.jpg
- cover.jpg
- building-01.png
- gangnam_night.jpg

[나쁜 예시]
- 성수 사진.jpg (한글+공백)
- 카드뉴스 커버.png (한글+공백)

[권장 사양]
- 크기: 1200×1500px 이상
- 비율: 4:5 (세로로 긴 사진)
- 형식: JPG 또는 PNG

[사용법]
1. 이 폴더에 사진 저장
2. 저에게 파일명 알려주기
3. 카드뉴스 HTML 파일에 자동 반영
